# 流程管理与表单收集系统 - 界面规划

## 1. 核心页面列表
1.  **流程模板列表 (Template Management)**: 展示所有模板，支持搜索、分类、启用/禁用、版本管理及快速复制。
2.  **可视化表单设计器 (Form Designer)**: 核心画布，左侧字段库（文本、数字、单选、多选、文件等），中间预览，右侧属性配置（必填、占位符、文件限制等）。
3.  **任务下发配置 (Task Distribution)**: 选择模板后，设置任务名称、截止时间、公告提示、指定填报人群（弹窗/列表选择）。
4.  **数据收集后台 (Data Dashboard)**: 汇总查看所有提交数据，支持详情预览、批量导出 Excel、附件下载。

## 2. 视觉特征
- **主色调**: 红色 (#C53030) 用于 Logo、主按钮、激活状态、关键路径。
- **布局**: 左侧导航栏（收纳功能模块），顶部全局操作，主体内容区域采用卡片式布局。
- **交互**: 侧边弹窗 (Drawer) 或居中模态框 (Modal) 处理表单属性和人员选择。

## 3. 填报端逻辑
- 响应式表单布局，支持附件实时上传进度条，草稿自动保存提醒。
