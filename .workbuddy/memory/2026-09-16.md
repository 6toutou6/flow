## 弹窗固定高度（10:57~11:20）

**皇上要求**：「弹窗都要固定好高度」—— 指臣最近动过的三个弹窗，各阶段/各状态下不要跳高跳矮。

| 弹窗 | 变化源 | 修法 | 实测 |
|---|---|---|---|
| `ImportMemberModal`（批量导入人员） | 出现「校验未通过」清单时撑高 | `::v-deep .el-dialog__body { height: 300px; overflow-y: auto }` | 初始 300 / 出错后 **300** |
| `UserPicker`（选人 + 逐人任务名） | 未选/已选、逐人/统一模式切换 | `::v-deep .el-dialog__body { height: 424px; max-height: 70vh; overflow-y: auto }` | 未选 562 / 已选 3 人 **562** |
| `GeneratePeriodModal`（生成期次） | 人员 0 人（空态）vs N 人（列表）**且整窗原本 975px 超出视口** | 空态与列表**统一 `height: 232px`**（列表内部滚动）；再给 body 加 `max-height: calc(90vh - 150px) + 滚动`、`top="5vh"` | 列表恒 232；弹窗 975 → **534**，底部 565 < 视口 633 |

**要点**：
- 「固定高度」的落点是 **`.el-dialog__body`**（`::v-deep` 穿透 scoped），不是给内部各块单独设高 —— 一处设好，各状态的差异就都被它吸收。
- 内容多到可能超屏的弹窗（生成期次），要用 **`height` 固定 + `max-height` 兜底** 的组合：`height` 保证不跳动、`max-height` 保证不超屏，配合 `top` 调小。
- 空态与列表**必须同高**，否则「0 人 → 有人」时会跳一下（本次把 `.gpd-empty` 从 `padding: 26px` 改成 `height: 232px` + flex 居中）。
