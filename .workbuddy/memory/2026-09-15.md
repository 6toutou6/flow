排查启动方式时发现 `mvn package` 跑不通：

```
Failed to execute goal maven-surefire-plugin:3.5.2:test (default-test)：Unable to load the mojo 'test'
A required class is missing: org/apache/maven/plugins/surefire/SurefireReportParameters
```

**根因**：本地离线仓库 `/usr/local/apache-maven-3.9.8/mvn_resp/org/apache/maven/plugins/maven-surefire-plugin/` 下 2.22.2 / 3.1.2 / 3.2.5 / 3.5.2 **四个版本的 jar 都只有 40~45K**（正常应数百 K），且都不含 `SurefireReportParameters` 类 —— 是残缺/占位文件。`-DskipTests` 与 `-Dmaven.test.skip=true` **都绕不过**（这只跳过"执行"，插件仍要被**加载**，加载即失败）。`flow-service/pom.xml` 未指定 surefire 版本，用的是 Maven 默认 3.5.2。

**影响与对策**：
- ✅ 不受影响：`mvn -o compile`、`mvn -o spring-boot:run`（不经过 surefire）—— 本地开发调试照常。
