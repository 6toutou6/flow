## 修复：编辑保存报"xxx不存在"（11:21，根因：前端 Number() 破坏 32 位主键）
- **症状**：编辑任务、编辑下发配置、设计流程保存时都提示"xxx不存在"
- **根因**：主键改为 varchar(32) 后，前端多处把从 URL query / 组件取到的 32 位字符串 id 用 `Number()` 转换 → **NaN** → 后端按 NaN 查 → "模板不存在/任务不存在/配置不存在"
- **修复 8 处**（7 个文件 + 1 个 prop）：
  1. `views/formdesigner/index.vue`：`templateId: Number(this.templateId)` → 字符串（保存流程核心）；`getTemplateUsage(Number(...))` → 去 Number；`:template-id="Number(templateId)"` → 去 Number
  2. `views/flowdispatch/EditTask.vue`：`taskId = Number($route.query.id)` → `$route.query.id || null`
  3. `views/flowdispatch/ConfigTemplateEdit.vue`：`templateId = Number($route.query.id)` → `|| null`
  4. `views/flowdispatch/PeriodFlow.vue`：handlerId Number → 字符串
  5. `views/flowdispatch/PersonView.vue`：taskId Number → 字符串；`ids.indexOf(Number(id))` → `indexOf(id)`（移除人员失败）
  6. `views/flowdispatch/PeriodUsers.vue`：`status = Number(filters.status)` → 直接字符串（中文状态被 NaN 破坏）
  7. `views/flowdispatch/index.vue`：flashId/flashPeriod Number → 字符串（高亮失效）
  8. `views/formdesigner/components/VersionListModal.vue`：prop templateId `type: Number` → `[String, Number]`
- **后端确认无此问题**：TemplateFlowSaveDTO.templateId 是 String、无 parseLong 残留
- **验证**：设计流程保存"流程保存成功"、编辑任务（taskId 32 位加载+保存入库）、编辑下发配置（加载+更新成功入库）全部通过
- **教训**：32 位主键迁移后，前端禁止对 id 做 Number()/parseInt()；URL query 取 id 直接用字符串
