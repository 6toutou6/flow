## 第六次精修 — 圆角收紧 (正式权威感)

### 问题
用户反馈圆角太圆（8px/10px/12px），不够官方正式。

### 方案
企业级系统圆角应克制→棱角分明。Design Token 收窄：

| 令牌 | 旧值 | 新值 | 用途 |
|------|------|------|------|
| `$radius-sm` | 4px | **2px** | 标签/徽章/小元素 |
| `$radius-md` | 8px | **3px** | 按钮/输入框/卡片 |
| `$radius-lg` | 12px | **4px** | 弹窗/大面板 |
| `$radius-xl` | 16px | **6px** | 极少使用 |
| `$radius-2xl` | 20px | **8px** | 极少使用 |

### 批量映射
- 10px → 3px（卡片/面板/分区容器）
- 8px → 3px（按钮/模态框/次要卡片）
- 6px → 2px（输入框/小型按钮）
- 12px → 4px（大标签/弹窗内容）
- 20px → 6px（超圆chip→正式）
- 5px → 2px（方向按钮）

### 统计
- **291 处替换**，涉及 **42 个文件**
- variables.scss Token 更新 + common.scss 变量引用更新
- 保留: login 卡片 18px（门户页入口可稍大）、progress-bar 9999px（胶囊条）
